# Публикация и сдача — пошагово

По присланным правилам стоп-код: **29 сентября 2026, 23:59 МСК**. Сохраните ссылки в кабинете заранее и завершите публикацию до этой минуты. После дедлайна не коммитьте и не пушьте в сданную ветку, не меняйте материалы и не запускайте обновление стенда.

## 1. Создать публичный репозиторий

На github.com войдите в свой аккаунт → «+» → New repository. Название, например, `finni-lct2026`. Выберите Public. Можно включить Add a README file, чтобы сразу появилась ветка main. Создайте репозиторий.

В репозитории: Add file → Upload files. Перетащите **всё содержимое распакованной папки Finni-GitHub-ready**, а не сам ZIP и не внешнюю папку. README.md, index.html, app, android, materials должны находиться сразу в корне. Подтвердите замену стартового README содержимым комплекта. Сообщение коммита: `Finni 2.2.0 submission`. Сохраните в main.

Проверьте, что загрузились также `.gitignore` и `.nojekyll`. В комплекте меньше 100 файлов, каждый меньше 25 MiB — подходит для загрузки через браузер. Если интерфейс предлагает pull request, завершите его слияние в main до дедлайна.

## 2. Включить работающий прототип

Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save. Именно root, не /docs. Дождитесь успешного развёртывания в Actions и ссылки в Pages.

Ожидаемый адрес обычного проектного репозитория: `https://ВАШ-ЛОГИН.github.io/finni-lct2026/`. При другом имени замените его. Это шаблон адреса, не уже созданный сайт. Открытие корня переводит в app/.

Откройте сайт в приватном окне, войдите finni / 1111, откройте задания и комнату. Проверьте загрузку изображений. Локальные сохранения не переносятся на опубликованный адрес. В About репозитория укажите проверенный адрес сайта как Website.

## 3. Проверить материалы

В приватном окне без входа в GitHub откройте репозиторий и скачайте PDF, PPTX, APK из materials. PPTX можно скачать и открыть; предварительный просмотр на GitHub не обязателен. Если форма требует именно PDF презентации, до дедлайна экспортируйте предоставленный PPTX в PDF через PowerPoint, проверьте его и загрузите как дополнительный файл. Основной PPTX в комплекте сохранён без изменений.

APK устанавливается самостоятельно, файл .apk.idsig для обычной установки не нужен. Проверьте установку и запуск на физическом Android, если устройство доступно. Резервное демонстрационное видео комплект не содержит.

## 4. Заполнить форму

При имени репозитория finni-lct2026 замените USER на свой логин:

| Поле | Ссылка |
|---|---|
| Репозиторий | https://github.com/USER/finni-lct2026 |
| Документация | https://USER.github.io/finni-lct2026/materials/Finni-Documentation-FINAL.pdf |
| Презентация | https://USER.github.io/finni-lct2026/materials/Finni-LCT2026-FINAL.pptx |
| Прототип | https://USER.github.io/finni-lct2026/ |
| Дополнительные материалы | https://github.com/USER/finni-lct2026/tree/main/materials |

В комментарии, если поле есть: «Демо-профили: finni / 1111, luna / 2222. APK и документы находятся в materials. Игра работает без серверной базы, сохранения локальные».

Если Pages ещё не готов, заранее сохраните ссылку на публичный репозиторий в обязательных полях — присланные правила допускают дублирование ссылок. Затем до дедлайна замените поле прототипа на проверенный работающий сайт. Не выдавайте localhost за внешний стенд. Сохраните форму и проверьте, что значения остались после повторного открытия; сделайте снимок подтверждения.

## 5. Зафиксировать финальную версию до стоп-кода

После последней загрузки и успешной публикации можно создать GitHub Release с новым тегом `v2.2.0-submission` на main. Прикрепите APK при желании — он уже есть в materials. Запишите SHA итогового коммита. Сдаваемая ссылка на документацию или файл также может указывать на этот тег. Тег не заменяет сохранение формы.

После стоп-кода не меняйте main, тег, PDF, PPTX, APK или опубликованный сайт. Не запускайте повторную публикацию. Для будущих улучшений используйте отдельную локальную копию или отдельный приватный проект, не связанный со сданными ссылками. Если публикация не успела завершиться до дедлайна, не скрывайте это и уточняйте порядок у организаторов.
