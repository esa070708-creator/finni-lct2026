# Питомец Финни — ЛЦТ 2026

Игра для знакомства детей 7–11 лет с бюджетом через заботу о виртуальном питомце. Задача № 6 Департамента финансов города Москвы. Финальная сборка прототипа: **2.2.0**.

## Быстрый запуск на компьютере

Нужен Python 3. Из корня репозитория:

```sh
python -m http.server 8766 --directory app
```

Открыть http://127.0.0.1:8766/ . Для Windows также подходит `py -m http.server 8766 --directory app`. Установка npm-пакетов и серверная база данных не нужны.

Демо-вход: **finni / 1111**, **luna / 2222**. Можно создать новый локальный профиль, назвать питомца и выбрать образ. Коды — демонстрационные заглушки, не защищённая серверная авторизация. Настоящие пароли использовать не нужно. Прогресс хранится на этом устройстве в localStorage; APK, localhost и GitHub Pages имеют отдельные сохранения.

## Как показать игру

Пройдите задания, сохраните план, купите нужное для питомца, отложите монеты. Покажите обзор дел перед переходом, предысторию новой главы и обновление заданий. После накопления подтвердите исполнение мечты: предмет появится в комнате. Перезапустите приложение и проверьте сохранение. Для сброса отдельного тестового профиля: «Для взрослого», пример 17 × 6, затем подтверждение сброса.

Старт — 35 монет, восемь заданий дают 94. При переходе после двух выполненных заданий начисляется 25. Заботливый день требует четырёх показателей от 90%, всех восьми заданий, сохранённого плана и чистого взноса в копилку от 15. После 3 таких дней — подросток, после 5 — герой. Ранний переход доступен после предупреждения, но без роста при невыполненных условиях. Уже заработанные достижения сохраняются.

## Проверки

Нужен Node.js 18+:

```sh
node test.cjs
```

Шесть групп сценариев проверяют ранний переход, строгие пороги, однократный зачёт, пять полных этапов, зависимости заданий и состав комнаты. Через браузер проверены обучение, переходы, сохранение и адаптивный интерфейс. APK подписан; проверка на физическом Android и исследование с детьми ещё не проведены.

## Структура

`app/` — автономный веб-интерфейс и ресурсы; `android/` — исходники Android WebView; `build.py` — сборка APK; `test.cjs` — сценарии движка; `materials/` — финальные файлы; `docs/` — техническое описание. `index.html` открывает игру на GitHub Pages. Каталог Android assets заполняется build.py из app/ и намеренно не дублируется в репозитории.

Для самостоятельной Android-сборки нужны Python, JDK, Build Tools 35, android.jar API 35 и собственный ключ. Переменные: FINNI_JDK, FINNI_BUILD_TOOLS, FINNI_ANDROID_JAR, FINNI_KEYSTORE, FINNI_KEY_PASSWORD. Команда: `python build.py`. Результат: build/Finni.apk. Alias ключа: finni. Закрытый ключ демонстрационной сборки не публикуется; иной ключ не позволяет установить обновление поверх существующего APK.

## Границы и материалы

Нет реальных платежей, рекламы, облачной синхронизации и админки. Учебные темы и варианты заданий повторяются циклами. Иллюстрации и шаблон презентации предоставлены для проекта; открытая публикация репозитория сама по себе не предоставляет лицензию на их свободное повторное использование. Автоматическое обновление зависимостей и плановые публикации не настроены.

Файлы PDF, PPTX и APK включены без изменения содержимого. SHA256SUMS.txt фиксирует контрольные суммы файлов комплекта. История разработки в исходном ZIP отсутствовала: при загрузке GitHub создаст первый настоящий коммит, предыдущие коммиты не имитируются.
